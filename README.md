# Python Snake Game (Turtle Edition)

A classic Snake game built with Python's built-in `turtle` library. It requires NO external dependencies and runs right out of the box!

## Features
- Smooth snake movement using Arrow Keys.
- Scoring system with High Score tracking.
- Works on any Python installation (no `pip install` required).

## How to Play

1. **Run the game**:
   ```bash
   python Snake.py
   ```
2. **Controls**:
   - **Arrow Keys**: Change the snake's direction (Up, Down, Left, Right).

## Objective
Eat the red food to grow and increase your score. Avoid hitting the walls or your own tail!
